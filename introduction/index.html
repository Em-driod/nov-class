Understanding CSS z-index

z-index controls which overlapping element appears in front. Think of the values as layers: a larger z-index is closer to you, while a smaller one sits behind it.

For z-index to work in this example, each shape has position: absolute. The parent has position: relative, so the shapes are positioned inside the demo area. All styling is written directly in each element's style attribute.

Circle
z-index: 1
Square
z-index: 2
Diamond
z-index: 3
Pill
z-index: 4
Triangle
z-index: 5

What to notice

  1. The shapes overlap because they are absolutely positioned in the same relative parent.
  2. The circle (z-index 1) is behind the square (2), diamond (3), pill (4), and triangle (5).
  3. The triangle is drawn last in front because it has the highest z-index value.
  4. Changing a value changes the stacking order. For example, set the circle to z-index: 6 to bring it to the front.

Remember: z-index is not a measurement in pixels. It only sets stacking order, and it works within the element's stacking context.
