Callback with a Timeout

setTimeout takes a callback and a delay in milliseconds. The browser runs the callback after the delay.

Try it

Start the timer and see the callback run after about two seconds.

The timer has not started.

The callback

setTimeout(function () {
    console.log("The timeout is finished!");
}, 2000);

The callback runs after about 2 seconds. It does not pause the rest of the page.
