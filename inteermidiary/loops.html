Beginner JavaScript lesson

Loops, Functions, and the DOM

Learn how JavaScript can repeat work, find HTML elements, and respond when someone clicks a button.

1. What is a loop?

A loop repeats a piece of code. Use one when you need to do the same kind of work for several values, instead of writing the same instructions again and again.

A regular for loop

for (let number = 1; number <= 3; number++) {
    console.log(number);
}

The loop starts number at 1, keeps going while it is less than or equal to 3, and adds 1 after each turn. The console shows 1, then 2, then 3.

forEach for arrays

const colors = ["blue", "green", "yellow"];

colors.forEach(function (color) {
    console.log(color);
});

forEach runs the callback function once for each array item. On each turn, color contains the current item. It is especially useful when you want to do something to every matching element on a page.

2. What is the DOM?

DOM means Document Object Model. The browser turns the HTML page into objects that JavaScript can find and change. For example, JavaScript can find an element by its ID, update its text, or add a click listener to a button. 

const heading = document.querySelector("#page-title");
heading.textContent = "The heading has changed";

document represents this page. querySelector finds the first element matching a CSS selector. Here, #page-title means the element with id="page-title". textContent changes the text inside it.

To find several elements, use document.querySelectorAll(".some-class"). It returns a collection of matching elements. Use forEach to work with each one.

3. What is a function?

A function is a named, reusable block of instructions. You can call it whenever you need that work done. A function can also receive information (called a parameter). 

function greet(name) {
    return "Hello, " + name;
}

const message = greet("Maya");

In this example, name is a parameter. Calling greet("Maya") passes the value "Maya" into the function. return sends a result back to the caller.

5. Read the example JavaScript

  1. The data: products is an array. Each object stores a product name and price.
  2. Find the container: document.querySelector("#product-list") finds the empty HTML element where the product cards belong.
  3. Build each card: products.forEach(function (product) { ... }) runs once per product. The function parameter product is the current object.
  4. Put the cards on the page: insertAdjacentHTML adds each card's HTML inside the container.
  5. Find all Add buttons: querySelectorAll(".add-to-cart") returns every button with that class.
  6. Listen for clicks: The second forEach adds a click listener to each button. When clicked, its function increases cartCount and updates the cart text in the DOM.

Remember: An event listener waits for an event, such as a click. A loop helps you attach the same listener to many elements. The function inside addEventListener runs later, when the click happens.

The complete internal JavaScript

This is the same JavaScript used by the demo. It is inside the HTML file's <script> element, so no separate JavaScript file is needed. 

const products = [
    { name: "Notebook", price: 5 },
    { name: "Pencil set", price: 3 },
    { name: "Backpack", price: 25 }
];

const productList = document.querySelector("#product-list");
let cartCount = 0;

products.forEach(function (product) {
    productList.insertAdjacentHTML(
        "beforeend",
        `<article class="rounded-lg border border-slate-200 p-4">
            <h3 class="font-bold">${product.name}</h3>
            <p class="mt-1 text-slate-600">$${product.price}</p>
            <button class="add-to-cart mt-3 rounded bg-blue-600 px-3 py-2
                text-white hover:bg-blue-700">Add to Cart</button>
        </article>`
    );
});

document.querySelectorAll(".add-to-cart").forEach(function (button) {
    button.addEventListener("click", function () {
        cartCount++;
        document.querySelector("#cart-count").textContent = cartCount;
        document.querySelector("#demo-message").textContent =
            "One item added to your cart.";
    });
});
