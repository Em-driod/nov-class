Callback Functions

A callback is a function passed to another function, to be called later.

Try it

Enter your name and the callback will display a personalized greeting.

Your greeting will appear here.

How the callback works

  1. greet receives the name and a callback function.
  2. greet creates a greeting and passes it to the callback.
  3. The callback displays the greeting on this page.
function greet(name, callback) {
    callback("Good morning, " + name + "!");
}

greet("Emmanuel", function (message) {
    console.log(message);
});
