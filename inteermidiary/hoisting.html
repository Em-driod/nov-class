JavaScript Hoisting

Hoisting describes how JavaScript processes declarations before running code. It does not mean that the source code is physically moved.

Try it

The demo calls a function before its declaration and reads a var before assigning it.

Click the button to see the results.

What to notice

  • Function declarations can be called before their declaration.
  • A var declaration is initialized to undefined until its assignment runs.
  • let and const are not usable before their declaration; that period is called the temporal dead zone.
